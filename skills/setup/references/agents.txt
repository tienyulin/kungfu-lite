# 各 agent 的接線定義，sync.sh 逐行讀。欄位以空白分隔，路徑用 ~ 開頭、不可含空白：
# 名稱 偵測目錄 守則目標 守則接法 hook目標 hook接法
# 守則接法：import（檔尾加 @路徑 引入行）| symlink（指向 store 的守則正本）
# hook接法：json（settings.json 的 hooks.SessionStart）| json-named（同 json，hook 多 name 欄）
#           | toml（config.toml 檔尾加 [[hooks.SessionStart]]）| script（產生可執行 script）
#           | none（該 agent 無指令型 hook，跳過）
# 新增 agent：加一行即可；接法不在上列時才需要改 sync.sh。
claude   ~/.claude          ~/.claude/CLAUDE.md               import  ~/.claude/settings.json          json
codex    ~/.codex           ~/.codex/AGENTS.md                symlink ~/.codex/config.toml             toml
gemini   ~/.gemini          ~/.gemini/GEMINI.md               symlink ~/.gemini/settings.json          json-named
opencode ~/.config/opencode ~/.config/opencode/AGENTS.md      symlink -                                none
cline    ~/Documents/Cline  ~/Documents/Cline/Rules/AGENTS.md symlink ~/Documents/Cline/Hooks/TaskStart script
