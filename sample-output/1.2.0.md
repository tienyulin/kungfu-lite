# 1.2.0 版本說明

## 新功能

- 訂單列表新增狀態篩選功能，方便查找特定狀態的訂單
- 支援以 Email 登入，提供更多登入選項

## 問題修正

- 修正匯出檔名重複的問題
- 修復大量資料匯出時逾時的問題
- 修復匯出報表時日期時區錯誤的問題

## 重要變更與升級注意

**受影響功能**：舊版 API（v1）/v1/export endpoint 將停用，需遷移至 v2

**升級步驟**：
1. 將呼叫改為 /v2/export（API 參數保持不變）
2. 留意回傳格式變更：舊版回傳單一 CSV 檔，新版改為 zip 壓縮檔
3. 確認客戶端的解壓流程能正常處理新的回傳格式
4. 測試完成後上線
