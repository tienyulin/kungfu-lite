# 查詢回收筒

## 這個功能做什麼

DBA 接到誤刪申請單時，先確認該表是否還在回收筒、能不能救回，再決定是否進行救回。
也可以列出某個 schema 底下回收筒內的全部表。每日使用數次；查詢結果供 DBA 判斷
後續處理，系統不會自動接著做任何事。

## 誰可以用這個功能

只有 DBA 能用，系統要強制擋下其他人。

## 特別名詞與分類

| 名詞 | 是什麼意思／系統怎麼分辨 |
|---|---|
| 回收筒 | Oracle 的 RECYCLEBIN：被 DROP 的表在空間被回收前的暫存區，期間可救回 |
| 能不能救 | 回收筒紀錄還沒被資料庫空間回收，就能救；被回收了就救不回來 |

## 輸入

| 參數名稱 | 型態 | 必填？ | 預設值 | 輸入限制／要先檢查什麼 | 說明 |
|---|---|---|---|---|---|
| schema | 文字 | 必填 | — | 不能空白；大小寫不敏感（輸入小寫也要查得到） | 表所屬的 schema |
| table_name | 文字 | 選填 | — | 查單一表時必填；不能空白；大小寫不敏感 | 要查的表名；不提供時列出該 schema 回收筒內的全部表 |

## 輸出

### 查單一表

| 欄位名稱 | 型態 | 說明 |
|---|---|---|
| in_recyclebin | 是/否 | 表是否在回收筒裡 |
| can_restore | 是/否 | 能否救回（表在回收筒時才有意義） |
| reason | 文字 | 不能救的原因（例：空間已被資料庫回收）；能救或表不在回收筒時無值 |

### 列全部

回傳該 schema 回收筒內全部表的清單，最新掉進回收筒的排前面。每筆包含：

| 欄位名稱 | 型態 | 說明 |
|---|---|---|
| original_table_name | 文字 | 原表名 |
| recyclebin_object_name | 文字 | 回收筒內的物件名（BIN$ 開頭，為 Oracle 自動命名） |
| drop_time | 日期時間 | 掉進回收筒的時間 |
| can_restore | 是/否 | 能否救回 |

回收筒是空的就回空清單，不算錯誤。

## 開始前先確認

- schema 不能空白
- 查單一表時，table_name 也不能空白

## 步驟

1. 查詢回收筒
   - 怎麼做：依輸入的 schema（與 table_name，如有）查詢回收筒。查單一表且查到
     多筆同名紀錄（同一張表被 DROP 過多次）時，以最新掉進回收筒的那一筆判斷能不能救
2. 整理結果回傳
   - 怎麼做：把查詢結果整理成「輸出」定義的欄位回傳；列全部時依掉進回收筒的時間
     由新到舊排序

## 怎麼算成功

- 查單一表：表不在回收筒也算查詢成功，如實回報「不在回收筒」，不是錯誤
- 列全部：回收筒為空時回空清單，也算成功

## 同一個對象能重複做嗎

可以重複查詢，沒有次數或頻率限制。

## 可能出什麼錯、出錯了怎麼辦

- schema 不存在 → 回報「schema 不存在」（與「回收筒裡沒東西」是兩回事，不能混用）
- 表在回收筒裡查不到 → 回報「不在回收筒」，不是錯誤
- 連不上 Oracle 或查詢逾時 → 回報系統錯誤，由 DBA 自行重試，系統不自動重試

## 範圍外

- 查詢結果列出的物件名本來就是 BIN$ 開頭的 Oracle 自動命名，不需要處理或轉換

## 測試例子

1. schema=scott, table_name=emp，表在回收筒且能救 → 成功，in_recyclebin=是、can_restore=是
2. schema=scott, table_name=EMP 與 table_name=emp → 兩者結果相同（大小寫不敏感）
3. schema=scott, table_name=nonexistent，表不在回收筒 → 成功，in_recyclebin=否
4. schema=scott, table_name=emp，表在回收筒但空間已被回收 → 成功，in_recyclebin=是、can_restore=否、reason=空間已被資料庫回收
5. schema=nonexistent → 回報「schema 不存在」
6. schema=scott（不給 table_name），回收筒有多張表 → 成功，清單依掉入時間新到舊排序
7. schema=scott（不給 table_name），回收筒為空 → 成功，回空清單
8. schema=（空白）→ 被擋，回報輸入錯誤
9. schema=scott, table_name=（空白）→ 被擋，回報輸入錯誤
10. schema=scott, table_name=emp，該表被 DROP 多次、回收筒有多筆 → 以最新一筆判斷，回傳其狀態
