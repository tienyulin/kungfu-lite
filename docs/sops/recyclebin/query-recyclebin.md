# 查詢回收筒

## 這個功能做什麼

DBA 接到誤刪申請單時先查，確認那張表還在不在回收筒、能不能救，再決定要不要走救回流程。也可以列出某個 schema 底下回收筒裡全部的表。一天大概用個幾次。查完就是人看，決定下一步。

## 誰可以用這個功能

只有 DBA 能用。系統要強制擋其他人。

## 特別名詞與分類

| 名詞 | 是什麼意思／系統怎麼分辨 |
|---|---|
| 回收筒 | Oracle 的 RECYCLEBIN，使用者誤刪表後，表先掉進回收筒，可以在一定時間內救回 |
| 能不能救 | 回收筒紀錄還沒被資料庫空間回收；如果空間已被回收掉，就救不了那張表 |

## 輸入

| 參數名稱 | 型態 | 必填？ | 預設值 | 輸入限制／要先檢查什麼 | 說明 |
|---|---|---|---|---|---|
| schema | 文字 | 必填 | — | 不能空白；大小寫不敏感（系統自己對應） | 表所屬的 schema |
| table_name | 文字 | 選填 | — | 查單一表時必填；不能空白；大小寫不敏感（系統自己對應） | 要查的表名；不提供此參數時列出該 schema 底下回收筒的全部表 |

## 輸出

### 查單一表

| 欄位名稱 | 型態 | 說明 |
|---|---|---|
| in_recyclebin | 是/否 | 表是否在回收筒裡 |
| can_restore | 是/否 | 能否救回（如果表在回收筒的話） |
| reason | 文字 | 不能救的原因，例如「空間已被資料庫回收掉」（如果不能救的話；能救或表不在回收筒時此欄位無值） |

### 列全部

回傳該 schema 底下回收筒裡全部表的清單，照最新掉進去的排前面。每筆資料包含：

| 欄位名稱 | 型態 | 說明 |
|---|---|---|
| original_table_name | 文字 | 原表名 |
| recyclebin_object_name | 文字 | 回收筒裡的物件名（BIN$ 開頭） |
| drop_time | 日期時間 | 掉進回收筒的時間 |
| can_restore | 是/否 | 能否救回 |

清單為空時回傳空陣列，不是錯誤。

## 開始前先確認

- schema 名不能空白
- 查單一表時，table_name 也不能空白

## 步驟

1. 連 Oracle 查回收筒
   - 怎麼做：根據輸入的 schema 和 table_name（如果有的話）查詢。若是查單一表且查到多筆同名資料（同一張表被 DROP 過好幾次），挑最新那筆判斷能不能救

2. 整理結果回傳
   - 怎麼做：把查詢結果整理成輸出表定義的欄位回傳；列全部時照掉進回收筒的時間新到舊排序

## 怎麼算成功

- 查單一表：表不在回收筒也算成功，回傳「不在回收筒」這個事實（不是錯誤）
- 列全部：回收筒是空的就回空清單，也算成功

## 同一個對象能重複做嗎

可以重複查，沒限制、不用擋頻率。

## 可能出什麼錯、出錯了怎麼辦

- schema 不存在 → 回報「schema 不存在」
- 表名在回收筒裡查不到（table_name 有給但查不到） → 回「不在回收筒」（不是錯誤）
- 連不上 Oracle 或超時 → 回報系統錯誤，DBA 自己重試（不用自動重試）

## 範圍外／已知的怪現象

- 查詢列出的物件名本來就是 BIN$ 開頭的亂碼，不是壞掉；那是 Oracle 回收筒的正常命名

## 測試例子

1. schema=scott, table_name=emp, 表在回收筒且能救 → 成功回傳 in_recyclebin=是, can_restore=是
2. schema=scott, table_name=EMP（大寫）+ schema=scott, table_name=emp（小寫） → 兩者應回傳相同結果（大小寫不敏感測試）
3. schema=scott, table_name=nonexistent, 表根本不在回收筒 → 成功回傳 in_recyclebin=否
4. schema=scott, table_name=emp, 表在回收筒但不能救（空間已被回收） → 成功回傳 in_recyclebin=是, can_restore=否, reason=「空間已被資料庫回收掉」
5. schema=nonexistent → 回報錯誤「schema 不存在」
6. schema=scott（不提供 table_name，列全部） → 回收筒有多張表，最新的排前面 → 成功回傳排序正確的清單
7. schema=scott（不提供 table_name，列全部） → 回收筒沒東西 → 成功回傳空陣列
8. schema=（空白）→ 因「schema 不能空白」被擋，回報輸入錯誤
9. schema=scott, table_name=（空白）→ 因「查單表時 table_name 不能空白」被擋，回報輸入錯誤
10. schema=scott, table_name=emp, 該表被 DROP 多次回收筒有多筆 → 查詢挑最新那筆判斷能不能救 → 成功回傳最新筆的狀態
